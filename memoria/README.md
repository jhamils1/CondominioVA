# Memoria de trabajo

Esta carpeta permite retomar el desarrollo leyendo hechos, decisiones y evidencia del repositorio. No es una base de datos ni una memoria automática de ChatGPT. Debe incluirse en el control de versiones mediante una revisión y commit posteriores; crear archivos no equivale a haberlos guardado en Git.

| Documento | Uso |
| --- | --- |
| [Estado actual](estado-actual.md) | Última etapa, alcance autorizado y punto de reanudación |
| [Pendientes](pendientes.md) | Prioridad, dependencias y bloqueos |
| [Historial](historial-trabajo.md) | Secuencia resumida de trabajo y decisiones |
| [Cambios](cambios-realizados.md) | Archivos y motivo de cambios significativos |
| [Pruebas](pruebas.md) | Comandos, entorno, resultados y límites |

Al iniciar, leer estado y pendientes; consultar contexto y fuentes relacionadas. Al terminar trabajo significativo aprobado, actualizar esos cinco documentos sin duplicar informes. Registrar fecha, resultado, pruebas ejecutadas y límites; si algo quedó a medias, señalar el punto exacto. Solo registrar decisiones aprobadas como tales. Conservar evidencias anteriores como históricas y enlazarlas, no copiar conversaciones completas ni datos personales.
